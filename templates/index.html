Core Features

Why Choose CropAdvisor AI?

Our system combines machine learning with live weather data to deliver intelligent, accurate crop recommendations tailored to your soil and climate.

Random Forest ML

Trained on real crop datasets with 7 key features — N, P, K, temperature, humidity, pH, and rainfall — for precise predictions.

Weather API

Automatically fetches temperature and humidity from OpenWeatherMap based on your city. No manual weather input needed.

Soil Analysis

Input your soil's Nitrogen, Phosphorus, Potassium levels and pH value to get data-driven agricultural insights.

High Accuracy

Random Forest ensemble method achieves ~97% accuracy by combining multiple decision trees for robust predictions.

Real-Time Results

Get instant crop recommendations with confidence scores. No waiting — results appear in seconds with detailed crop info.

Responsive Design

Works beautifully on desktop, tablet, and mobile. Use it anywhere — even in the field on your phone.

How It Works

Three Simple Steps

From input to prediction in seconds — powered by Python Flask, scikit-learn, and the OpenWeatherMap API.

01

Enter Soil Data

Input your soil's Nitrogen (N), Phosphorus (P), Potassium (K), and pH value along with your city name.

02

Fetch Weather

Our backend calls OpenWeatherMap API to fetch real-time temperature and humidity for your city automatically.

03

Get Prediction

The Random Forest model combines all 7 features and predicts the best crop with a confidence score.
